# Nexora frontend

React + Vite frontend for the Nexora cybercrime reporting guidance prototype.

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. In the terminal run:

   ```powershell
   npm install
   npm run dev
   ```

4. Open the local URL shown by Vite, usually `http://localhost:5173/`.

## Current scope

This is the frontend prototype. Incident selection, navigation feedback, and checklist progress work in the browser. File extraction, case persistence, AI/RAG, and AWS services are not connected yet. Those will be implemented module by module.

For suspected financial cyber fraud in India, call 1930 immediately and use the official portal at https://cybercrime.gov.in/. Do not wait for the prototype to process evidence.
